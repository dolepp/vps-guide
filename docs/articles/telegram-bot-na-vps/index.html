Telegram-бот на VPS: запуск 24/7 через systemd

Бот на домашнем компьютере работает, пока включён компьютер. Чтобы он отвечал круглосуточно, его переносят на VPS. Для большинства ботов хватает минимального тарифа: 1 ядро и 512 МБ – 1 ГБ RAM. Ниже полный путь на примере Python и библиотеки aiogram (подходит и для python-telegram-bot, и для Telethon).

Что понадобится

  • VPS с Ubuntu 22.04/24.04 (как выбрать);
  • токен бота от @BotFather;
  • код бота в папке или Git-репозитории.

Перед запуском сделайте базовую настройку безопасности сервера.

1. Установите Python и зависимости

sudo apt update
sudo apt install -y python3 python3-venv python3-pip git

2. Загрузите проект

cd ~
git clone https://github.com/ВАШ_ЛОГИН/ВАШ_БОТ.git bot
cd bot

Без Git можно скопировать файлы командой scp -r ./bot deploy@IP:~/ со своего компьютера.

3. Виртуальное окружение

python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

4. Храните токен в переменных окружения

Не кладите токен в код. Создайте файл .env и закройте права:

echo 'BOT_TOKEN=123456:ABC...' > .env
chmod 600 .env

5. Автозапуск через systemd

sudo nano /etc/systemd/system/mybot.service
[Unit]
Description=My Telegram Bot
After=network-online.target
Wants=network-online.target

[Service]
User=deploy
WorkingDirectory=/home/deploy/bot
EnvironmentFile=/home/deploy/bot/.env
ExecStart=/home/deploy/bot/venv/bin/python main.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
sudo systemctl daemon-reload
sudo systemctl enable --now mybot
sudo systemctl status mybot

Restart=always перезапустит бота при падении, а enable — после перезагрузки сервера.

6. Логи

journalctl -u mybot -f          # живой поток
journalctl -u mybot --since "1 hour ago"

7. Обновление бота

cd ~/bot && git pull
source venv/bin/activate && pip install -r requirements.txt
sudo systemctl restart mybot
Бот готов, осталось где его запустить

Частые проблемы

  • Бот не стартует: смотрите journalctl -u mybot -n 50 — чаще всего не хватает зависимости или переменной окружения.
  • Ошибка «Conflict: terminated by other getUpdates»: бот уже запущен в другом месте (на домашнем ПК). Остановите копию.
  • Бот падает от нехватки памяти: добавьте swap или возьмите тариф побольше.
  • Нужна база данных: для простых задач хватит SQLite, для нагрузки — PostgreSQL.

Частые вопросы

Сколько стоит содержать Telegram-бота на VPS?

Для небольшого бота подходит самый дешёвый тариф VPS. Точную цену смотрите у выбранного хостера.

Можно ли запускать несколько ботов на одном VPS?

Да. Делайте для каждого отдельный systemd-сервис и виртуальное окружение. Ресурсов 1 ГБ RAM хватит на несколько лёгких ботов.

Как сделать, чтобы бот не падал?

Параметр Restart=always в systemd перезапускает процесс автоматически, а логи через journalctl помогают найти причину сбоев.
