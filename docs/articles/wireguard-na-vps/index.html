WireGuard — быстрый и простой VPN-протокол, встроенный в ядро Linux. Личный сервер полезен, чтобы безопасно работать в публичном Wi-Fi, получать доступ к домашней сети или рабочим ресурсам и шифровать трафик между своими устройствами. Используйте его в соответствии с законодательством вашей страны и правилами хостера.

Требования

Подойдёт самый скромный VPS: 1 ядро и 512 МБ RAM. Нужна KVM-виртуализация и Ubuntu 22.04/24.04. Предварительно выполните базовую настройку.

1. Установка

sudo apt update
sudo apt install -y wireguard

2. Ключи сервера и клиента

cd /etc/wireguard
umask 077
wg genkey | tee server.key | wg pubkey > server.pub
wg genkey | tee client.key | wg pubkey > client.pub

3. Включите маршрутизацию

echo 'net.ipv4.ip_forward=1' | sudo tee /etc/sysctl.d/99-wg.conf
sudo sysctl --system

4. Конфиг сервера

Узнайте имя внешнего интерфейса командой ip route | grep default (часто eth0 или ens3) и подставьте вместо eth0.

sudo nano /etc/wireguard/wg0.conf
[Interface]
Address = 10.8.0.1/24
ListenPort = 51820
PrivateKey = СОДЕРЖИМОЕ_server.key
PostUp = iptables -t nat -A POSTROUTING -s 10.8.0.0/24 -o eth0 -j MASQUERADE
PostDown = iptables -t nat -D POSTROUTING -s 10.8.0.0/24 -o eth0 -j MASQUERADE

[Peer]
PublicKey = СОДЕРЖИМОЕ_client.pub
AllowedIPs = 10.8.0.2/32

5. Файрвол и запуск

sudo ufw allow 51820/udp
sudo ufw route allow in on wg0 out on eth0
sudo systemctl enable --now wg-quick@wg0
sudo wg show

6. Конфиг клиента

[Interface]
PrivateKey = СОДЕРЖИМОЕ_client.key
Address = 10.8.0.2/32
DNS = 1.1.1.1

[Peer]
PublicKey = СОДЕРЖИМОЕ_server.pub
Endpoint = IP_СЕРВЕРА:51820
AllowedIPs = 0.0.0.0/0, ::/0
PersistentKeepalive = 25

Импортируйте файл в приложение WireGuard (Windows, macOS, Linux, Android, iOS). Для телефона удобно сгенерировать QR-код: sudo apt install qrencode && qrencode -t ansiutf8 < client.conf.

Проверка

  • после подключения ваш внешний IP должен стать IP сервера;
  • sudo wg show покажет последний handshake и объём трафика;
  • если интернета нет — проверьте имя интерфейса в PostUp и разрешённый UDP-порт.

Добавить ещё одно устройство

Сгенерируйте новую пару ключей и добавьте в wg0.conf ещё один блок [Peer] с адресом 10.8.0.3/32, затем выполните sudo systemctl restart wg-quick@wg0.

Частые вопросы

WireGuard или OpenVPN — что выбрать?

WireGuard проще в настройке, быстрее и экономнее по ресурсам. OpenVPN нужен в случаях, когда требуется TCP или специфичная совместимость.

Сколько устройств выдержит минимальный VPS?

Десятки устройств с лёгким трафиком. Ограничивает чаще пропускная способность канала, а не процессор.

Почему не работает интернет через VPN?

Чаще всего неверно указан внешний интерфейс в PostUp, не включён ip_forward или закрыт UDP-порт.
