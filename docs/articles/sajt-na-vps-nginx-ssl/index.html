Сайт на VPS: Nginx + HTTPS за 20 минут

Собственный VPS даёт полный контроль над сайтом: вы выбираете стек, не зависите от ограничений тарифа и платите за ресурсы. Разберём самый универсальный вариант: Nginx раздаёт статические файлы (или проксирует на ваше приложение) и работает по HTTPS.

Что нужно

  • VPS на Ubuntu с базовой защитой;
  • домен и доступ к его DNS;
  • файлы сайта.

1. Направьте домен на сервер

В DNS-панели регистратора создайте A-записи для example.com и www.example.com на IP сервера (для IPv6 — AAAA). Обновление обычно занимает от нескольких минут до пары часов. Проверка:

dig +short example.com

2. Установите Nginx

sudo apt update
sudo apt install -y nginx
sudo ufw allow 'Nginx Full'
sudo systemctl enable --now nginx

3. Конфигурация сайта

sudo mkdir -p /var/www/example.com
sudo chown -R $USER:$USER /var/www/example.com
echo '<h1>Привет, VPS!</h1>' > /var/www/example.com/index.html
sudo nano /etc/nginx/sites-available/example.com
server {
    listen 80;
    listen [::]:80;
    server_name example.com www.example.com;
    root /var/www/example.com;
    index index.html;

    location / {
        try_files $uri $uri/ =404;
    }
}
sudo ln -s /etc/nginx/sites-available/example.com /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx

4. Бесплатный SSL (Let's Encrypt)

sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d example.com -d www.example.com

Certbot сам добавит HTTPS в конфиг и настроит редирект с HTTP. Автопродление проверьте командой:

sudo certbot renew --dry-run

5. Если у вас приложение (Node, Python), а не статика

Nginx работает как обратный прокси:

location / {
    proxy_pass http://127.0.0.1:3000;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-Proto $scheme;
}

Само приложение запускайте через systemd так же, как бота.

6. Ускорение и безопасность

  • включите gzip или brotli, кэширование статики (expires 30d);
  • скройте версию Nginx: server_tokens off;;
  • настройте бэкап каталога сайта и базы данных.

Частые вопросы

Нужно ли покупать SSL-сертификат?

Нет, для большинства сайтов хватает бесплатных сертификатов Let's Encrypt с автопродлением.

Сколько ресурсов нужно для небольшого сайта?

Для статики или лёгкого блога достаточно 1 ядра и 1 ГБ RAM, WordPress с базой комфортнее на 2 ГБ.

Что лучше: Nginx или Apache?

Nginx экономнее по памяти и хорош как веб-сервер и обратный прокси. Apache удобен, если нужны .htaccess-файлы.
