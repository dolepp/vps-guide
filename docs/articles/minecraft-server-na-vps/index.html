Свой Minecraft-сервер на VPS: от установки до автозапуска

Свой сервер Minecraft даёт полный контроль над плагинами, миром и правилами. Платформа Paper — быстрая форк-версия ванильного сервера с поддержкой плагинов. Ниже установка на Ubuntu VPS.

Какие ресурсы нужны

ИгроковRAMCPU
1–5 (ваниль)2–3 ГБ2 ядра
5–15 + плагины4–6 ГБ2–4 ядра
15+ или моды8 ГБ+4+ ядра

Minecraft сильно нагружает одно ядро, поэтому важна высокая частота процессора, а не их количество. Диск лучше NVMe — мир грузится быстрее. Выбирайте локацию ближе к игрокам. Подробнее — в чек-листе выбора VPS.

1. Установите Java

Современные версии Minecraft требуют Java 21 (проверьте требование вашей версии):

sudo apt update
sudo apt install -y openjdk-21-jre-headless
java -version

2. Отдельный пользователь и папка

sudo adduser --system --group --home /opt/minecraft minecraft
sudo -u minecraft mkdir -p /opt/minecraft/server
cd /opt/minecraft/server

3. Скачайте Paper

Свежий jar-файл берите на официальном сайте PaperMC (papermc.io/downloads), сохраните как paper.jar в папку сервера и примите EULA:

sudo -u minecraft sh -c 'echo "eula=true" > /opt/minecraft/server/eula.txt'

4. Автозапуск через systemd

sudo nano /etc/systemd/system/minecraft.service
[Unit]
Description=Minecraft Server
After=network.target

[Service]
User=minecraft
WorkingDirectory=/opt/minecraft/server
ExecStart=/usr/bin/java -Xms2G -Xmx3G -jar paper.jar --nogui
Restart=on-failure
RestartSec=10

[Install]
WantedBy=multi-user.target
sudo systemctl daemon-reload
sudo systemctl enable --now minecraft
sudo ufw allow 25565/tcp

Не отдавайте Java всю память VPS: оставьте 500 МБ – 1 ГБ системе.

5. Защита сервера

В server.properties включите white-list=true и enforce-whitelist=true, затем добавляйте игроков командой whitelist add Ник в консоли. Для публичных серверов пригодится DDoS-защита хостера.

Для игрового сервера важны частота ядра и пинг

Я использую VPS-хостинг Aeza: быстрая выдача сервера, оплата без танцев, выбор локаций. Актуальные тарифы и наличие локаций смотрите на сайте — они меняются.

Посмотреть тарифы Aeza →Партнёрская ссылка: сервис получает вознаграждение, цена для вас не меняется.

6. Бэкапы мира

sudo tar czf /root/world-$(date +%F).tar.gz -C /opt/minecraft/server world

Положите команду в cron и храните копии вне сервера.

Частые вопросы

Сколько RAM нужно для Minecraft-сервера?

Для небольшой компании хватает 2–4 ГБ. Для плагинов и десятков игроков нужно 6–8 ГБ и больше.

Чем Paper лучше ванильного сервера?

Paper оптимизирован по производительности и поддерживает плагины Bukkit/Spigot.

Какой порт открывать?

Стандартный порт Minecraft Java Edition — 25565/tcp.
